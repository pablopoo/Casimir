# Casimir user walkthrough

A self-contained offline guide to installing the private preview, publishing a
notes app and reviewing it in the Casimir console, adapted from Void.

- Open [index.html](index.html) for the illustrated walkthrough.
- [WALKTHROUGH.md](WALKTHROUGH.md) contains the same user journey in Markdown.
- [INSTALLATION.md](INSTALLATION.md) explains supported operator installation
  and administrator enrollment. Release archives and credentials are separate.
- [SOURCES.md](SOURCES.md) records verified behavior and limits.
- [CAPTURE-MANIFEST.json](CAPTURE-MANIFEST.json) binds unchanged screenshots.

The screenshots use synthetic identities and data. The [MIT notice](LICENSE)
and third-party notices are retained. This guide contains no credentials or
release binaries. No website or release has been published.
